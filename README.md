# Serveur de visualisation, édition et versionnage SQLite des feuilles Markdown

This is a lightweight and autonomous web application to view, edit, and version Markdown documents.

## Installation

```bash
pip install -r requirements.txt
```

## Running the application

```bash
python -m server.main
# Or run with uvicorn:
# uvicorn server.main:app --reload
```

## Running tests

```bash
pytest
```
